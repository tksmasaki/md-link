# Privacy Policy for MD Link

MD Link does not collect, store, or transmit any personal data to any external server.

The extension does not store any data, locally or remotely. When you trigger it
(via the keyboard shortcut or the toolbar icon), it reads the **title and URL of
the currently active tab**, formats them as a Markdown link (`[title](url)`), and
writes the result to your clipboard. Nothing is persisted, logged, or sent
anywhere.

MD Link does not use analytics, tracking, advertising, or remote code of any kind.

## Permissions

| Permission | Purpose |
| --- | --- |
| `activeTab` | Read the title and URL of the current tab — only when you invoke the extension — in order to copy it to the clipboard as a Markdown link. No page content is read and no data is sent anywhere. |
